## Path para aprender C

Todo el roadmap esta en el ```roadmap.pdf``` de este repo donde abarcaremos tanto el lenguaje C como DSAs puros y profundos
Todo el codigo esta organizado por carpetas tipo <numero>-<tema> desde el nivel basico/intermedio hasta hardcore

Cada nivel tiene su propia evaluacion. Para el aprendizaje con C, no vamos a utilizar ninguna IA generativa, pura documentacion, stack overflow y Geeks for Geeks.
