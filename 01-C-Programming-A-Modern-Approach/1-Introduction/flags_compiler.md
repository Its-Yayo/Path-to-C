Command-line GCC's options

-Wall -> Causes the compiler to produce warnings messages when it detects possible errors
-W -> Issues all warning messages beyond those produced by -Wall
-pendanic -> Issues all warnings required by the C standard. Causes programs that use nonstandard features to be rejected
-ansi -> Turns off features of GCC that aren't standard GCC and enables a few features that are normally disabled
