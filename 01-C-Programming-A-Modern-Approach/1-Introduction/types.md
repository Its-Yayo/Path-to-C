int - largest int value is 2,147,483,647, but can be as small as 32,767
float - can store ints with decimal values

---

variables must be declared first as their data type

```
static char my_variable[200];
float my_number;
int hello;
```

main function has to have these

```
int main(void) {
  declarations;
  statements;
}
```

%d works for integers
%f works for floats, by default %f displays a number with 6 digits after the decimal point ex. 123.<453124>

%.2f for 2 decimal digits after the decimal point ex. 3922.<21>

---

scanf() reads a value and scores it into a variable

```
scanf(%d, &number); // variable scored to number
```
